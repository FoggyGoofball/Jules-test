A quick command line script in python to parse genomes from Grandroids and output them as a spreadsheet for easier comprehension.
I didn't code anything for this and decided to try AI coding tools instead.  Seems to work well enough.
In order to use it, you will need to install python on your system if you haven't got it already.
Next, put your genome file into the same folder as the "parser.py" script and rename it to "input.txt"
Doubleclick on parser.py and almost instantly you will generate a spreadsheet called output.csv and a file called limits.txt
limits.txt provides a list of tolerances and thresholds for various chemistry within an individual genome
